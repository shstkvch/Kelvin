# Tutorials

Learn Kelvin by building real applications.

## Step-by-Step Guides

| Tutorial | Time | What You'll Learn |
|----------|------|-------------------|
| [Guestbook](/tutorials/guestbook) | 5 min | Public views, authentication, basic CRUD |
| [Blog](/tutorials/blog) | 15 min | Relationships, roles, custom actions |
| [Todo App](/tutorials/todo-app) | 10 min | State management, filtering |

## Prerequisites

Before starting these tutorials, make sure you've:

1. [Installed Kelvin](/getting-started/installation)
2. Tried the [Quickstart](/getting-started/quickstart)

## Tutorial Format

Each tutorial follows the same structure:

1. **What You'll Build** - Overview of the finished app
2. **Step-by-Step Instructions** - Guided walkthrough
3. **Test Your App** - API and admin panel testing
4. **What's Next** - Suggested next steps

## Getting Help

If you get stuck:

- Check the [FAQ](/faq) for common issues
- Review the [Concepts](/concepts/) for deeper explanations
- Open an issue on [GitHub](https://github.com/shstkvch/Kelvin/issues)
