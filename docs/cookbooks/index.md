# Cookbooks

Practical recipes for common patterns.

## Available Recipes

| Recipe | Description |
|--------|-------------|
| [Soft Delete](/cookbooks/soft-delete) | Mark records as deleted instead of removing them |
| [Deployment](/cookbooks/deployment) | Deploy to Docker, Fly.io, Railway, Render |
| [Email Notifications](/cookbooks/email-notifications) | Send emails on create/update actions |

## Recipe Format

Each cookbook entry includes:

1. **Problem** - What you're trying to solve
2. **Solution** - The Kelvin code
3. **How It Works** - Explanation of the approach
4. **Variations** - Alternative approaches
